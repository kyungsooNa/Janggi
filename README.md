# 승강급 장기

브라우저에서 AI와 두는 한국 장기. 휴대폰 세로 화면 기준으로 만들었다.

## 실행

```bash
npm start          # http://localhost:8000 에서 index.html 열기
npm test           # 규칙 엔진 · AI · 급수 테스트
npm run build      # dist/janggi.html 한 파일로 묶기 (서버 없이 더블클릭으로 실행 가능)
```

## 대국 방식

- 진영은 지난 판에 진 사람이 초(먼저 둠)를 잡는다. 첫 판은 무작위이고, 메뉴에서 '항상 초/한'으로 고정하거나 상차림 팝업에서 바꿀 수 있다. 한은 덤 1.5점을 받는다.
- 기물 글자는 한은 굵은 명조 정자(Shippori Mincho B1, 빨강), 초는 붓글씨 정자(Yuji Boku, 파랑)로 새겨 모양으로도 구분한다.
- 기물은 들려서 포물선을 그리며 날아가 "탁" 소리와 함께 내려앉고, 잡힌 기물은 튕겨 나간다(효과음은 메뉴에서 끌 수 있다).
- 수 되감기: 대국 중에는 기보(💬) 버튼에서 '되감아 보기'나 기보의 수를 누르면, 대국이 끝난 뒤에는 결과 화면의 '수 되감기'로 둔 수를 한 수씩 앞뒤로 볼 수 있다(◀ ▶, 키보드 ← →). 보는 동안에도 대국은 계속 진행된다.
- 대국 기록: 끝낸 대국(최근 100판)과 전적·승률이 저장되고, 기록을 누르면 판에서 한 수씩 기보를 다시 볼 수 있다(◀ ▶ 버튼, 키보드 ← →).
- 시작 전에 상차림(마상마상 · 상마상마 · 마상상마 · 상마마상)을 20초 안에 고른다. 상대 상차림은 기본이 무작위이고, 팝업에서 상대 기물을 눌러 직접 바꾸거나 다시 무작위로 돌릴 수 있다.
- 시간: 기본 5분 + 초읽기 30초 3회. 초읽기를 다 쓰면 시간패.
- 승패는 카카오장기 방식으로 가린다.
  - 외통승
  - 기물승: 한쪽 점수(한은 덤 포함)가 10점 이하일 때 점수가 앞선 쪽이 한수 쉼을 하면(또는 양쪽이 연속으로 쉬면) 앞선 쪽이 이긴다. AI도 앞서 있으면 한수 쉼으로 바로 기물승을 가져간다.
  - 외통 불가 기물승: 양쪽 모두 차·마·상이 없고 포+졸이 2개 이하이며, 엔진이 양쪽 다 6수 안에 외통이 없다고 확인하면 바로 점수 높은 쪽이 이긴다(한게임의 '비기는 기물 형태' 판정과 같은 취지). 이 기물 조합은 무작위 국면 실험에서 외통이 0~3%만 나왔고, 실제로 외통이 있는 국면은 끝내지 않는다.
  - 200수 기물승: 200수(양쪽 수와 한수 쉼을 모두 셈)가 되면 점수 높은 쪽이 이긴다. 마지막 수가 잡기나 장군이면 판정하지 않고 계속 두며, 300수에서는 무조건 판정한다. 180수부터 제목에 남은 수가 보이고, 20수·10수 남았을 때 알려 준다.
- 버튼: 한수 쉼(장군 중이거나 반복수면 불가), 기권, 아이템(무르기 3회 · 훈수 3회).

## 급수 (18급 ~ 9단)

AI는 항상 **내 급수와 같은 실력**으로 둔다. 이기면 승급 점수 +1, 지면 -1.
+3이 되면 한 단계 승급, -3이 되면 한 단계 강급한다. 급수는 브라우저(localStorage)에 저장된다.

급수가 오를수록 AI가 더 깊이 읽고, 생각 시간이 늘고, 일부러 두는 실수가 줄어든다
(`js/ranks.js`의 `aiParams`).

| 구간 | 최대 탐색 깊이 | 실수 확률 | 실수할 때 최대 손해 |
|---|---|---|---|
| 18급~15급 | 2수 | 30%~25% | 3점 |
| 14급~10급 | 3수 | 23%~17% | 1.8점 |
| 9급~5급 | 4수 | 15%~9% | 1점 |
| 4급~1급 | 5수 | 7%~2% | 0.6점 |
| 1단~3단 / 4단~6단 / 7단~8단 / 9단 | 6수 / 7수 / 8수 / 9수 | 없음 | - |

장군을 받고 있을 때는 어느 급수든 실수하지 않는다.

급수 이름은 AI끼리의 상대적인 순서일 뿐 사람 기력과 맞춘 것은 아니다.

이웃 급수끼리 대국시킨 결과(평가 v2, 위 급수 승률, 초·한 번갈아 8판씩):

| 대결 | 위 급수 승률 |
|---|---|
| 18급 vs 14급 | 8/8 (100%) |
| 14급 vs 10급 | 7/8 (88%) |
| 10급 vs 6급 | 8/8 (100%) |
| 6급 vs 2급 | 8/8 (100%) |
| 2급 vs 2단 | 6/8 (75%) |
| 2단 vs 5단 | 8/8 (100%) |
| 5단 vs 7단 | 8/8 (100%) |
| 7단 vs 9단 | 7/8 (88%) |
`node scripts/tournament.js`로 이웃 급수끼리 대국시켜 위 급수의 승률을 확인할 수 있고,
`node bench/search-bench.js 6`으로 탐색 속도를 잴 수 있다.

국면 평가는 v2(`evaluateV2`)를 쓴다. 기물 점수에 차·마 활동성, 포의 국면별 가치, 궁 안전(사 수, 궁성 근처 침입),
졸 연결을 더했다. `node bench/ab-eval.js --time 300`으로 이전 평가와 같은 생각 시간에서 맞붙일 수 있고,
한 수 0.3초 60판에서 67%(±12%), 0.8초 40판에서 73%(±14%)를 v2가 이겼다.

## 구조

| 파일 | 내용 |
|---|---|
| `js/engine.js` | 규칙: 수 생성(궁성 대각선, 포 규칙, 마·상 멱), 장군·외통 판정, 점수, 기보 표기 |
| `js/ai.js` | 알파-베타(PVS) 탐색 + 치환표 + 킬러/히스토리 수 순서 + 널 무브 + 늦은 수 감축 + 정지 탐색, 급수별 실수 모델 |
| `js/ranks.js` | 급수 목록, 급수별 AI 설정, 승강급 계산 |
| `js/ai-worker.js` | AI를 Web Worker에서 실행 (안 되면 메인 스레드로 대체) |
| `js/main.js` | 화면, 입력, 시계, 팝업 |
| `css/style.css` | 화면 스타일 |

## 반복수

같은 국면(판 모양 + 둘 차례)을 세 번째로 만드는 수와 한수 쉼은 둘 수 없다. 단, 궁과 사가 움직이는 수는 반복돼도 둘 수 있다. 반복수를 빼면 둘 수 있는 수가 없을 때만 예외로 허용한다. AI도 같은 규칙을 따른다.

빅장 규칙은 아직 넣지 않았다.
